# Mathematical model

The core relation is \(\Delta v=v_e\ln(m_0/m_f)\), with
\(v_e=I_{sp}g_0\). An ideal power-limited electric thruster is represented by
\(F=2\eta P_e/v_e\), so \(\dot m=F/v_e\). For NEP, waste heat is
\(Q=P_e(1/\eta_c-1)\), and a first-order radiator is
\(A=Q/(\epsilon\sigma T^4)\). Radiator mass is \(A\rho_A\).

Mass closure iterates tank mass as a stated fraction of propellant. NEP is only
accepted by the duration screen if \(F/m_0\ge\Delta v/t\). That condition is
necessary for the specified average velocity change under an idealized constant
thrust interpretation; it is neither sufficient for, nor a substitute for, a
heliocentric low-thrust trajectory solution.
